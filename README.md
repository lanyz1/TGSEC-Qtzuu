## 技能入口(skill_view)

- about-security — Use when needing structured pentest skills or payloads
- claude-bughunter — Use when doing bug bounty or disclosed-report analysis
- hack-skills — Use when performing web/API/binary/AD security or CTF
- secatlas — Use when needing Chinese pentest technique cards or cases
- skill-arsenal — Use when needing pentest skills across 17 attack categories
- stopen — Use when running automated pentesting with OODA loop
- web-sec — Use when needing web security exploit/penetration reference
