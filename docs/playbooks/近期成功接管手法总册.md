### 接管优先级（主登录卡死时）

1. 未授权 upload/download/resource → 种 XSS  
2. `/24` 打开 8089 控制面 → on-demand SSRF  
3. iM WebWS 清单 / 假设备控制面  
4. OpenAPI/422 schema  
5. 最后才密码侧信道（禁开局喷）

### 必记坑

- download/resource ≠ CF 静态 URL  
- 8089 代理不要填攻击机 `127.0.0.1:9050`  
- page snippet ~120 字  
- `undefined`+ms 时间戳 HMAC 假阳  
- mem* 假百度 decoy
