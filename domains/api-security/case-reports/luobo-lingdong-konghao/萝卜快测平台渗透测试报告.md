## 严重发现

### C1. 未授权访问手机号检测记录 + 手机号数据 ZIP 任意下载 (IDOR)
- **位置**: `https://www.lingdongdata.com/number-check/system/screenlog/{id}` (GET)
- **复现**: 无需任何认证, 通过递增 ID 即可读取全部检测记录:
  - `GET /number-check/system/screenlog/20752` → 返回记录 (用户 `13271046329`, 2026-08-04, 检测 6700 个号码)
  - ID 范围 **1 ~ 20752+** 全部可遍历; 抽样 30 条: 平均每条 20,336 个号码, 单条最高 26 万个
  - 每条记录泄露: 客户用户名 (手机号/邮箱)、检测数量、状态、结果统计, 以及 **`zipFile` 直链**
- **数据下载复现**: 记录中的 `zipFile` 直链无需认证即可下载:
  - `GET /number-check/profile/upload/zip/2026/8/4/1785842809119/1785842809119.zip` → 200 `application/zip` (35KB)
  - ZIP 内含 4 个分类文件 (实号 5581 个 / 空号 100 / 停机 332 / 沉默 687), 内容为**真实手机号明文** (如 `13600979871`)
- **影响**: **严重 PII 泄露** — 约 2 万+ 条记录, 估算涉及数亿条手机号数据; 任意人可枚举 ID 批量下载客户检测的手机号文件。同时泄露服务器路径 `/home/ruoyi/uploadPath/` (确认 RuoYi 部署)。
- **注**: 已确认下载验证后立即删除本地 PII 样本, 未留存。

## 中危发现

### M1. Swagger API 文档暴露
- `GET /number-check/swagger-ui/index.html` → 200; `GET /number-check/v2/api-docs` → 200
- 泄露: "若依管理系统_接口文档", 版本 3.8.6; 测试控制器 `test-controller` (`/number-check/test/user/*` CRUD, 实际 401 保护)
- 影响: API 攻击面全量暴露, 便于定向攻击

### M2. 前端 JS 内嵌 RSA 私钥
- `GET /admin/assets/jsencrypt.9003a9f2.js` → 内含 2048 位 RSA 私钥 `kt` 与 512 位加密公钥 `Ut`
- 影响: 密钥材料暴露; 可解密客户端 remember-me cookie 等加密数据

### M3. 多个未鉴权 API 端点
- `GET /number-check/system/connectioninfo/list` → 未鉴权返回客服联系方式 (微信 `konghaojiance678`, QQ `3766321749`)
- `GET /number-check/portal/selectContentList?pageSize=100` → 未鉴权返回 90 条内容记录 (含 `/profile/upload/YYYY/MM/DD/` 上传路径)
- `GET /number-check/system/screentask/selectWaitTask` → 未鉴权返回任务数据
- 影响: 数据/结构信息泄露

### M4. 上传文件可预测路径直接访问
- `GET /number-check/profile/upload/2026/07/29/1_20260729122004A162.png` → 200 (2.3MB, 经内容接口泄露的路径)
- 影响: 上传目录下文件可直接获取 (含可能的用户上传号码文件)

### M5. 内网/基础设施信息泄露

- `.git` 源码泄露额外暴露: 旧源站 `113.45.187.50`, 关联系统 `wxcheck.zjjytech.com`

### M6. 注册接口不校验图形验证码
