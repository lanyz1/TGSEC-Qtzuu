# Web 授权机制绕过实战靶场 第一课：卡密校验与时效限制突破
> 
> 同学们好，欢迎进入《Web 端授权机制实战攻防》系列课程的第一课。本靶场专为安全学习爱好者打造，聚焦**卡密授权体系的常见实现缺陷与绕过思路**，覆盖本地前端校验、服务端接口校验、时效周期控制、资源下发鉴权四大核心场景。请大家严格在合法授权的前提下完成练习，所有技术仅用于安全防护能力提升与漏洞防御研究。

## 📚 课程目标

通过本靶场的实操练习，你将系统掌握：

1. 快速识别并绕过前端本地卡密校验逻辑
2. 分析服务端卡密校验的常见漏洞点并实现权限突破
3. 定位并破解 12 小时周期时效验证机制，解除授权时间限制
4. 构造合规请求欺骗服务端，正常下发受保护的音效等资源文件

## 🖥️ 靶场环境说明

本靶场完整模拟了一套典型的「卡密授权 + 资源按需下发」业务系统，还原了真实开发中的常见授权逻辑：

- 采用**前端本地校验 + 服务端二次校验**的双层卡密验证架构
- 授权卡密默认绑定**12 小时有效期**，到期自动吊销授权，资源接口拒绝访问
- 音效等媒体资源不会前置打包，仅在卡密验证通过后由服务端动态下发
- 系统内置了多维度的授权逻辑缺陷，供大家逐步拆解、逐层突破

## 🎯 核心挑战关卡

### 关卡 1：前端本地校验绕过

**场景描述**：卡密授权页面首先通过前端 JS 执行卡密格式、前缀规则校验，校验不通过则直接拦截，无法向服务端发起授权请求。
**挑战目标**：不输入有效卡密，绕过前端验证逻辑，成功向服务端提交授权请求。

### 关卡 2：服务端卡密校验绕过

**场景描述**：前端校验被突破后，服务端仍会对卡密进行数据库层面的合法性校验，仅合法卡密会返回授权凭证与状态标识。
**挑战目标**：通过分析接口逻辑、构造请求参数，绕过服务端卡密校验，获取系统有效授权状态。

### 关卡 3：12 小时时效限制突破

**场景描述**：授权成功后，系统每 12 小时会强制校验卡密有效性，到期自动清空授权状态，音效等资源下发接口将直接拒绝访问。
**挑战目标**：定位时效校验的实现位置与逻辑，解除 12 小时的时间限制，实现授权状态永久生效。

### 关卡 4：服务端资源下发欺骗

**场景描述**：音效等媒体资源由服务端鉴权后动态下发地址，无有效授权时无法获取资源链接与文件内容。
**挑战目标**：构造合法请求欺骗服务端鉴权逻辑，在无正规卡密授权的情况下，成功获取并加载全部音效资源。

## 📖 知识点导学（教师精讲）

同学们在闯关过程中，可以围绕以下核心思路展开分析，不要死记答案，重点理解背后的逻辑缺陷：

1. **本地校验绕过的核心逻辑**
前端校验本质是「客户端自我验证」，所有代码逻辑都完全暴露在浏览器端。常见的突破方向包括：禁用页面 JS、Hook 关键校验函数、修改函数返回值、跳过校验直接调用授权成功后的业务函数。大家要记住一个核心原则：**所有客户端的校验都不可信，只能作为防错辅助，不能作为安全边界**。
2. **服务端校验绕过的思考方向**
服务端校验的缺陷通常出现在参数校验不严、逻辑判断分支遗漏、授权凭证可控等位置。大家可以重点关注接口的请求参数、返回体中的授权标识字段、Cookie/LocalStorage 中的状态标记，尝试通过参数篡改、越权访问、伪造授权凭证等方式突破验证。
3. **12 小时时效机制的破解思路**
时效校验的实现通常分为两种：一是客户端本地记录授权时间，到期本地触发失效逻辑；二是服务端签发带过期时间的 Token，到期后服务端主动拒绝请求。大家需要先通过抓包和调试定位时效校验的执行端，再对应通过修改本地时间、篡改 Token 过期时间、重放有效授权请求等方式绕过限制。
4. **资源下发欺骗的实现方法**
服务端下发资源的鉴权，本质是校验请求中携带的授权凭证。只要我们能构造出携带「合法授权标识」的资源请求，就能欺骗服务端返回资源文件。重点关注资源请求接口的鉴权参数，以及授权状态与资源接口的关联逻辑，找到鉴权的绕过点即可实现资源拉取。
