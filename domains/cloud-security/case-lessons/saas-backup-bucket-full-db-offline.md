## 链

运营打包控制台泄漏的 S3 凭据 → 枚举 10 桶 → `s3s3-*` 桶 `ceshi/<日期>/` = **各租户每 30 分钟自动整库备份**（文件名含租户+库名）→ 下载目标租户 `.sql.gz` → **与线上账号哈希交叉验证归属**（5,518 条 HMAC-MD5 一致）→ 离线全量解析 + 口令破解（全程零生产触达）

## 要点

- **SaaS 多租户备份桶 = 一桶打穿全平台**：同桶 19 租户整库（每 30 分钟一份）全可下
- **完整性证明法**（回答「是不是全部用户」）：对全部引用 `user_id` 的表逐表核对「引用 ID 不在主表的数量」→ 全为 0 ⇒ 主表完整（22,189 = 全量）
- 归属确认不靠猜：线上可登录账号哈希与备份库逐条比对，命中即锁定
- 离线闭环：解析 → SQLite → CSV → 破密；字典叠加身份证/生日/姓名个性化
- **口径纪律**：「747,965」= 平台级累计注册计数 ≠ 目标用户数（跨租户含注销）——报告单独澄清防误引
