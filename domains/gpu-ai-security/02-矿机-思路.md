# 02 · 矿机部署与保活思路

> 拿到 GPU root 后，如何占用算力（挖矿）并保证矿工不被杀、不丢币。
> 核心结论：**矿机不难部署，难的是「活着」和「不被抢」。**

---

## 一、矿机选择思路

### 1.1 按算力类型选币

| GPU | 推荐币种/算法 | 说明 |
|---|---|---|
| NVIDIA 消费级（30/40/50 系） | 内存密集型 / GPU 币 | 按显存与功耗比选 |
| 数据中心卡（A100/H100/L40S） | 高价值币 | 算力密度高，优先占用 |
| CPU-only 容器 | CPU 币 | 价值低，但聊胜于无 |

### 1.2 矿工二进制的隐蔽部署

- **命名伪装**：矿工二进制改名为系统进程样（如 `kworker-xx` / `systemd-xx` / `*-helper`）。
- **存放位置**：系统树深处（`/usr/lib/.xxx/`），或寄生已有目录。
- **体积**：用 `strip` 去符号，减小体积。
- **不落常见矿工特征名**：避免 `xmrig` / `nbminer` / `lolminer` / `trex` 等被扫描规则命中。

> 血训：.png 后缀伪装 ELF 可绕过「按后缀删文件」的运维习惯。

## 二、矿池接入思路

### 2.1 连接方式

```
stratum+ssl://<POOL_HOST>:<PORT>  --user <WALLET>/<WORKER_TAG>
```

- **优先 SSL 端口**：加密流量不易被 IDS 按明文特征识别。
- **Worker TAG**：用随机自然名（如 `worker-a` / `worker-b`），不带任何可追溯信息。
- **多矿池冗余**：主池失败自动切备用池（配置里写多个）。

### 2.2 钱包锚定（防抢币）

**这是保活的核心杀招**：
- 所有矿工进程的 `--user` 参数必须匹配**我方钱包**。
- 巡检发现钱包不符（被竞争者改过）→ **立即 kill，用正确钱包重启**。
- 钱包地址本身建议做**锚定校验**（部分校验位），防篡改。

```sh
# 巡检逻辑（伪代码）
for pid in $(pgrep -f miner):
    if wallet_of(pid) != OUR_WALLET:
        kill -9 pid
        start_miner_with(OUR_WALLET)
```

## 三、矿工保活体系

### 3.1 三层时间轴

```
秒级   进程 watchdog（30–60s 循环，flock/时间戳防并发自复制）
分钟级 cron / systemd timer（60s–15min）
开机级 systemd enabled + @reboot + rc.local
```

### 3.2 保活要点

- **先查后杀**：杀竞争者前先确认自己矿工在跑（保护运行中的）。
- **资源感知**：cgroup v2 → v1 → `/proc/meminfo` 三级降级探测，按内存分级调整线程数。
- **低优先级**：`nice +15`，不抢业务资源（抢资源=触发排查）。
- **日志最小化**：日志新鲜但进程死 = 复活信号；日志刷屏 = 告警信号。
- **线程数按核心数动态**，避免打满 CPU 触发监控。

### 3.3 自调度链（不依赖 cron）

```
sleep N → exec 心脏脚本 → sleep N → ...
```
> 关键修复：**不要用 flock 做单例**——fd 会被 sleep 子进程继承导致永久死锁。改用**时间戳防重入**（`.lastrun`，60s 窗口）或**按进程存在性去重**（扫 `/proc` 判 `sleep *SEED*` 是否已存在）。

## 四、独占：杀竞争者 + 夺回算力

### 4.1 竞争者识别

| 特征类型 | 例子 |
|---|---|
| 常见矿工进程名 | xmrig / krig / nbminer / lolminer / trex / SRBMiner / compute-gpu / gpu-adaptive |
| 伪装系统进程 | `.sysd` / `netprobe` / 假 `systemd-*` |
| 恶意文件 | `evil_*.ckpt` / `libcuda_*.so` / `cuda_snap_*.pkl` / `fleet_*.py` |
| 第三方 webshell | `/root/.srv_ws*` / `.ws.py` 等 |
| 未知监听端口 | 非白名单端口监听 |

### 4.2 处置动作

```
① 杀进程（按名 + 按钱包 + 按路径三重识别）
② 删文件（先 chattr -i，再删）
③ 清 SSH key（非白名单公钥全部剔除）
④ 清 cron/systemd 里的第三方条目
⑤ 端口哨兵：记录非白名单监听，持续监控
```

> 血训：**不要清理对方的痕迹**——清理行为本身会被记录，是更强的信号。只清理**会威胁到我方**的东西。

## 五、算力利用的两条路线

| 路线 | 说明 | 风险 |
|---|---|---|
| **挖矿** | 直接占用 GPU 挖币 | 中（有流量特征、功耗特征） |
| **推理/训练占用** | 跑自己的模型推理，混进业务流量 | 低（隐蔽性最好，但收益取决于用途） |

> 隐蔽性优先的场景（机主活跃值守）：**不要挂矿工**，只做低资源占用或干脆不做，专注持久控制权。

> **矿机部署是体力活，保活是脑力活，独占是狠活。三样缺一，算力就不是你的。**
