# 技术校准说明（基于 V3 持续演进）

这版保持原有“短句、口诀、金句、可直接喂 Agent”的风格，但把几类容易被攻防团队质疑的绝对化口径收紧：

1. **盲区不是证据**：pentest/BAS 验证结果只调整调查优先级和取证路径，不能自动把线上告警升档。
2. **端点不是唯一真相源**：端点可得时优先；SaaS、云控制面、网络设备、无代理工作负载可用网络+身份+API/控制面形成独立证据闭环。
3. **置信度与严重度拆开**：真假与轻重不是一回事；incident 不按 ATT&CK 阶段数判。
4. **ATT&CK 不强行贴标签**：ATT&CK 是 adversary behavior language，不是漏洞分类表。业务逻辑缺陷只有在观测行为吻合时才映射 ATT&CK。
5. **BOLA 不等于所有越权**：对象级授权、功能级授权、属性级授权、认证缺陷、状态机漏洞分别归类。
6. **K8s 可见性不绝对**：取决于 CNI/eBPF/运行时/传感器位置，不能用“经过/不经过宿主机网卡”一刀切。
7. **加密流量不设万能阈值**：周期、包长、JA3/JA4、证书、ASN 都是弱语义，必须回到 peer baseline 与实体上下文。
8. **WAF/EDR 验证从“绕过手册”改成“控制有效性验证”**：保留对抗视角，但避免把验证方法写成可复用规避步骤。
9. **不删测试证据**：测试流量使用 test_id 隔离并保留日志，方便审计与回归。
10. **响应动作受 Control/HITL 约束**：模型给建议，策略决定能不能自动执行。

## 保留的核心金句

> **特征负责提问，证据负责定性。**

> **盲区是 Prior，不是 Evidence。**

> **攻击路径是地图，不是现场。**

> **周期性说明“像机器”，不说明“是木马”。**

> **置信度管真假，严重度管轻重。**

> **Agent 可以提速判断，不能偷走控制权。**
