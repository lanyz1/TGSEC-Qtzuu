# AI 安全工程公式与金句速查

> 公式不是为了把安全变成数学题，而是为了让 Agent 少拍脑袋。

## 01｜异常

```text
异常度 = 偏离程度 × 基线可信度 × 上下文相关性
```

**偏离不是恶意。** 首次访问、凌晨执行、流量突增都只能证明“和平时不一样”。

> **异常负责叫醒你，不负责给攻击者定罪。**

## 02｜调查优先级

```text
调查优先级 = 资产价值 × 异常强度 × 暴露/可达性 × 盲区先验 × 时效性
```

红队/BAS 的 blind spot 放这里最合适：它告诉蓝队“哪里更值得先看”，而不是“这里一定被打了”。

> **盲区是 Prior，不是 Evidence。**

## 03｜证据

```text
证据强度 = Σ(证据权重 × 独立性 × 可靠性 × 因果贴合度) − 矛盾证据
```

参考排序：

```text
直接行为证据 > 跨源独立佐证 > 强上下文异常 > 统计异常 > 单一 IOC/指纹
```

> **一条硬证据，胜过十条像攻击。**

## 04｜置信度

```text
置信度 = 证据完整度 + 来源独立性 + 因果一致性 − 良性解释 − 关键证据缺口
```

不要把 WAF+NDR+SIEM 三条告警机械算成“三源”：如果三者都来自同一条网络会话或同一规则链，它们可能只是**一个事实被复制了三遍**。

> **日志条数不是证据数，独立来源才是。**

## 05｜严重度

```text
严重度 = 业务影响 × 权限级别 × 扩散半径 × 持久化能力 × 数据敏感度
```

```text
Confidence ≠ Severity
```

确认一台蜜罐被扫描，可以高置信低严重；核心域控出现弱凭据利用迹象，可以低置信但高优先。

> **置信度管真假，严重度管轻重。**

## 06｜因果

```text
A → B = 实体连续 + 时间顺序 + 机制成立 + 制品/状态连续
```

```text
时间接近 + IOC相似              = A ~ B
独立数据源确认同一行为          = A + B
状态真正从 A 传递并导致 B       = A → B
```

> **时间能排顺序，机制才能定因果。**

## 07｜业务逻辑漏洞

```text
授权成立 = 身份合法 ∩ 功能有权 ∩ 对象有权 ∩ 租户一致 ∩ 状态允许
```

任一关键集合不成立，都值得继续判断是哪类授权/状态机问题：

```text
身份合法 + 功能有权 + 对象无权 = BOLA 候选
身份合法 + 功能无权            = BFLA 候选
对象/功能都有权 + 状态不允许    = Workflow / State-Machine Flaw 候选
跨租户对象被访问               = Tenant Isolation Failure 候选
```

> **逻辑漏洞不看 payload 多花，看“谁能在什么状态下动谁的东西”。**

## 08｜加密流量

```text
可疑度 = 节律异常 + 包型稳定性 + 目的地上下文 + 资产角色偏离 + 端点/身份佐证
```

TLS、JA3/JA4、SNI、周期性都不是单独定罪项。

> **密文看不见内容，就看行为留下的形状。**

## 09｜响应

```text
响应强度 = 事实置信度 × 潜在影响 × 扩散速度 × 动作可逆性修正
```

同时受 Control 层约束：

```text
自动动作 = 策略允许 ∩ 证据达标 ∩ 资产允许 ∩ 动作可逆/有回滚 ∩ 不在强制人审清单
```

> **Agent 可以建议踩刹车，但刹车线是谁画的，必须由人和策略决定。**

## 10｜一句话总公式

```text
实体解析 + 基线偏离 + 权限/不变量违反 + 跨源证据 + 因果连续 − 良性解释
= 可解释的安全结论

可解释的安全结论 + 业务影响 + Control Policy
= 可执行的响应动作
```

> **特征负责提问，证据负责定性；风险负责排序，策略负责动作。**

# Security for AI 公式补充


```text
AI Agent 风险 = 不可信输入 × 可影响上下文 × Agent 权限 × Tool 能力 × 敏感资产可达性 × 控制缺口

Prompt Injection 实际风险 = 恶意/不可信指令进入 × 决策被影响 × 权限允许 × Tool 可执行 × Control 未阻断

有效权限 = 用户授权 ∩ Agent 身份 ∩ 当前任务范围 ∩ Tool ACL ∩ 数据域

Tool 调用许可 = Tool 有权 ∩ 参数合法 ∩ 对象有权 ∩ 数据域允许 ∩ 副作用可接受

知识可信度 = 来源可信 × 完整性 × 时效性 × 身份/租户边界 × 授权范围

Memory 写入许可 = 来源可追溯 ∩ Scope 正确 ∩ 无越权数据 ∩ 生命周期明确

动作风险 = 潜在影响 × 权限级别 × 扩散半径 × 不可逆性 × 不确定性

允许数据流出 = 请求者有权 ∩ 用途允许 ∩ 目标域允许 ∩ 最小必要 ∩ Policy 允许

系统级可利用性 = 输入可控 ∩ 决策可劫持 ∩ 权限可达 ∩ Tool 可执行 ∩ 副作用可产生 ∩ Control 未阻断
```

金句：
- **Prompt Injection 是入口，权限失控才是事故。**
- **模型可以提议动作，但模型不能给自己授权。**
- **权限不是 Prompt，权限必须在模型之外生效。**
- **检索到，不等于可信；记住了，更不等于事实。**
- **能读到，不等于能带走。**
- **别只测模型说了什么，要测系统最后做了什么。**
- **对攻击，沿证据链走；对自己，在权限笼子里跑。**
