# 案例课：源码站/内容站 — settings 与付费资源未授权

> 脱敏。Nuxt/PHP API 内容站、源码售卖常见。

## 高危模式

| 接口 | 问题 |
|------|------|
| `GET /api/v1/site/settings`（或同类） | 未授权返回 **Bot Token**、客服 chat_id、USDT 地址、功能开关 |
| `GET /posts/{id}` 或详情 | 未登录返回 **download.url + 解压密码** |
| login/register | captcha 全关 → 可爆破/批量注册刷返佣 |

## 影响

- Bot Token 有效 + webhook 空 → 可劫持推送/假客服（**报告只写风险，不教诈骗话术**）
- 付费资源直链白嫖
- 链上收款地址暴露（社工/钓鱼风险面，加固建议轮换与监控）

## 检查清单

- [ ] settings 是否必须鉴权；Token 类字段是否永远不下发前端
- [ ] 付费字段是否服务端鉴权（买后再签临时 URL）
- [ ] 验证码/邀请码策略
- [ ] JWT 算法与 secret 强度；uid 是否可篡改

## 增值审计（源码商品）

若业务售卖「工具源码」，抽测包内是否含 **硬编码第三方 Key/后台入口/明文库**（供应链与连带泄露）。  
报告描述风险类型，**不复制受害者助记词/私钥明文到知识库**。
