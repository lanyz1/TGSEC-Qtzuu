# [KB-AI-001] AI Agent 与 MCP 安全控制闭环

- **类别**: AI Agent / MCP / 供应链
- **信号**: Agent 根据网页、RAG、记忆或工具返回中的隐藏指令改变任务目标、调用不必要工具、访问越权资源、重复循环，或工具描述/Schema 在批准后发生变化。
- **原理**: Agent 将外部内容、工具描述、身份权限和执行环境组合在同一控制流中。若外部内容未与系统指令隔离、工具调用缺少服务端授权、完成判定依赖 Agent 自评，攻击者可能影响工具选择、数据边界或任务终止。MCP Server 的动态描述、Schema 漂移、跨 Server 命名冲突和凭据过度集中会扩大供应链影响面。
- **最小PoC**: 在隔离测试环境放置唯一无害标记 `AI_TEST_MARKER`，观察它是否改变工具选择、资源范围或任务完成判定；使用控制组、单变量变化和有限步数，不读取真实秘密、不外联、不执行破坏性动作。
- **判定**: 仅凭模型文本或工具成功不确认漏洞。需要保留原始输入、工具描述/Schema、调用序列、主体与资源、控制组差异、停止原因和副作用计数。
- **绕过与变体**: 直接/间接 Prompt 注入、RAG/记忆投毒、Tool/Rug Pull、Shadow Tool、Schema 漂移、跨 Server 冲突、Agent 循环失控、多 Agent 身份混淆、沙箱/宿主边界错误。
- **修复**: 外部内容分区并标注不可信；工具描述和 Schema 固定、签名、版本锁定并复审变更；所有资源授权在服务端按主体/租户/对象/动作执行；凭据最小权限、短时且不可被模型读取；独立完成判定；设置步数、Token、费用、外呼和副作用硬上限；代码执行采用隔离、只读根和最小挂载；记录完整审计事件。
- **复测**: 重新执行无害标记和控制组场景，确认工具选择、权限、资源范围和终止条件不再被外部内容改变；确认 Schema 变更、越权调用、循环和异常外呼被阻断并留有日志。
- **参考**: CWE-284、CWE-345、CWE-441、OWASP Top 10 for LLM Applications、OWASP Top 10 for Agentic Applications、MITRE ATLAS；本仓库 `references/agentic-ai/`；来源蒸馏记录见 `references/agentic-ai/来源与取舍.md`。
