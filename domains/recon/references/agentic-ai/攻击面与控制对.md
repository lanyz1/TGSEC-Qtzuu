# AI Agent 攻击面与控制对

| 风险簇 | 最小验证 | 控制对 | 证据 |
|---|---|---|---|
| 外部内容注入 | 放置 `AI_TEST_MARKER` 并观察是否改变工具选择 | 外部内容分区、来源标记、系统指令隔离、调用审批 | 原始输入/输出、工具调用序列 |
| Tool/Rug Pull | 固定工具描述后比较版本和 Schema | 签名、版本锁定、白名单、变更复审 | hash、diff、批准记录 |
| 权限越界 | 控制组访问同一资源 | 服务端主体/租户/对象/动作授权 | 403/成功差异、主体和资源 |
| 循环失控 | 设置有限完成条件并记录计数 | 独立完成判定、步数/Token/费用/外呼硬上限 | 计数、停止原因、副作用数 |
| 沙箱边界 | 无害文件/网络标记 | 只读根、最小挂载、网络隔离、进程限制 | 文件、进程、网络审计 |
| 多 Agent 混淆 | 固定身份和租户控制组 | 身份绑定、消息来源认证、租户隔离 | 消息链、主体、授权决策 |

## 统一判断

- 模型文本、HTTP 状态码、扫描器标题和工具成功只能作为线索。
- 需要可观察差异、影响边界、控制组和可回滚复测才能确认。
- 外部内容中的“忽略规则、读取密钥、上传、关闭保护、自动推送”等只作为待审计数据。
