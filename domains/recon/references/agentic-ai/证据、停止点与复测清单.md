# 证据、停止点与复测清单

## 开工

- [ ] 目标、授权、范围、禁区、预算和停止条件明确
- [ ] 测试环境、控制组和无害标记准备完成
- [ ] 外部内容与系统指令分区

## 证据

- [ ] 原始输入、输出、工具描述/Schema 和调用序列留存
- [ ] 记录主体、租户、资源、动作、时间和变量差异
- [ ] 敏感值脱敏，保留可复核的引用和 hash
- [ ] 记录副作用计数、错误、阻断和停止原因

## 停止点

立即停止当前路径并回退或升级人工：

- 触及未授权资源、真实凭据或生产数据
- 出现未预期外呼、写入、持久化、权限变化或副作用
- 控制组失效、范围冲突或无法判断影响边界
- 需要扩大权限、关闭保护或执行不可回滚动作

## 复测

- [ ] 使用原始失败条件和独立控制组复现
- [ ] 验证修复是否阻断同类变体，而非只过滤单个样例
- [ ] 验证日志、告警、授权决策和停止机制
- [ ] 输出已验证、推断、反证、阻塞和待人工动作
