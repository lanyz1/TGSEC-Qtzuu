# 收录规则

只保留直接支撑供应链攻击面分析、证据判断和评估案例的公开主来源：

1. 渗透方法论使用政府或 OWASP 官方指南；
2. 技术事实使用标准组织、政府机构或项目官方文档；
3. 搜索摘要、第三方博客和视频不作为结论依据；
4. 不镜像 PDF、网页、音视频或 Schema，只保存最小书目信息和链接；
5. 正式版、持续维护文档和版本化规范分别标注。

# 授权评估方法

## SRC-2026-1833 — NIST SP 800-115

- 状态：最终版，2008-09。
- URL：<https://csrc.nist.gov/pubs/sp/800/115/final>
- 用途：规划和执行技术安全测试、分析发现、形成缓解策略；支撑范围、证据和报告方法。

## SRC-2026-1834 — OWASP Web Security Testing Guide

- 状态：官方稳定网页版本。
- URL：<https://owasp.org/www-project-web-security-testing-guide/stable/>
- 用途：测试原则、威胁建模、入口识别、单项验证和报告框架。
- 边界：本专题只复用可迁移的方法，不把 Web 具体测试项混入供应链样本。

# 软件供应链案例事实

## SRC-2026-1801 — NTIA 2021 SBOM Minimum Elements

- 状态：正式发布，2021-07-12。
- URL：<https://www.ntia.gov/report/2021/minimum-elements-software-bill-materials-sbom>
- 用途：SBOM 定义、最小数据字段、自动化支持和实践流程。

## SRC-2026-1803 — NIST SP 800-218 SSDF 1.1

- 状态：最终版，2022-02。
- URL：<https://csrc.nist.gov/pubs/sp/800/218/final>
- 用途：组件来源数据和发布控制在安全开发生命周期中的位置。

## SRC-2026-1807 — CycloneDX 1.7

- 状态：版本 1.7。
- URL：<https://cyclonedx.org/specification/overview/>
- 用途：SBOM、依赖关系、组件身份、漏洞和 VEX 数据模型。

## SRC-2026-1808 — Package URL

- 状态：持续维护。
- URL：<https://github.com/package-url/purl-spec>
- 用途：软件包生态坐标；与内容摘要共同分析组件身份。

## SRC-2026-1809 — in-toto Attestation Framework

- 状态：框架 v1.2.0，Statement 类型为 v1。
- URL：<https://github.com/in-toto/attestation/blob/main/spec/v1/README.md>
- 用途：Envelope、Statement、Predicate 分层和 subject 摘要绑定。

## SRC-2026-1810 — SLSA 1.2

- 状态：正式版，2025-11-24。
- URL：<https://slsa.dev/spec/v1.2/>
- 用途：构建来源、制品验证、构建器信任和消费者期望。

## SRC-2026-1811 — Sigstore 安全与验证模型

- 状态：持续维护的官方文档。
- URL：<https://docs.sigstore.dev/about/security/>
- 用途：OIDC 身份、短期证书、透明日志、验证材料和信任限制。

## SRC-2026-1812 — CISA VEX Minimum Requirements

- 状态：正式公开资料，2023-04-21。
- URL：<https://www.cisa.gov/resources-tools/resources/minimum-requirements-vulnerability-exploitability-exchange-vex>
- 用途：VEX 产品、漏洞、状态、影响说明和处置说明。

# 使用边界

- 来源索引证明的是事实出处，不证明具体目标存在漏洞。
- 规范不等于测试授权；真实目标必须另行明确范围和允许动作。
- 版本性事实使用前应重新核验，推理样本不得冒充任何单一规范的原文要求。
