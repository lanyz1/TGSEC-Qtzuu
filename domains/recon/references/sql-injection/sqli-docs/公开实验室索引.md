# 使用边界

以下环境专门用于安全教学。只在其官方在线实验室或本机隔离实例中练习，不把相同操作用于未经授权的互联网目标。

## PortSwigger Web Security Academy

- 来源：`SRC-2026-0007`
- 形式：免费公开的在线学习路径与独立实验室。
- 覆盖：基础识别、查询上下文、UNION、错误型、布尔盲注、时间盲注、带外概念、二阶注入和修复。
- 本库使用方式：保存链接、进度和原创总结，不镜像课程正文或完整题解。

推荐顺序：

1. SQL 注入定义与检测。
2. `WHERE` 条件和业务逻辑变化。
3. UNION 结果形状概念。
4. 数据库类型与元数据差异。
5. 错误、布尔和时间信号。
6. 二阶注入。
7. 防护与修复。

每个实验只记录：

- 学习目标。
- 观察到的信号。
- 根因。
- 停止点。
- 修复方式。

不要把实验答案直接复制成仓库条目；应先用自己的语言抽象为技术卡片。

# 本地实验室基线

## 网络

- 监听回环地址。
- 容器端口不绑定 `0.0.0.0`。
- 无需外网时关闭容器出站网络。
- 不与生产 VPN、办公内网或云 VPC 桥接。

## 数据

- 使用项目自带种子数据。
- 不导入真实用户、订单、日志或凭据。
- 每轮练习可重置。
- 截图和日志在归档前检查 Token、Cookie、路径和个人信息。

## 主机

- 使用低权限容器或虚拟机。
- 不挂载 Docker Socket。
- 不挂载主目录或凭据目录。
- 固定公开镜像或发行版本并记录哈希。

# 建议练习单

## 练习一：根因卡片

从公开靶场选择一个基础 SQL 注入点，写出：

- 外部输入。
- 不安全 SQL 构造。
- 数据库执行 API。
- 可观察结果。
- 参数化修复。

## 练习二：误报对照

构造一个“输入会报类型错误但始终绑定参数”的安全接口，与真正字符串拼接的接口比较，练习区分错误与结构改变。

## 练习三：动态排序

实现固定排序字段与方向映射，验证：

- 合法选项正常。
- 未知选项被拒绝。
- SQL 结构不接受任意字符串。

## 练习四：二阶路径

在本机教学项目中模拟“安全保存、危险读取”的链路，然后把第二个查询改成参数化。重点记录跨阶段数据流，不扩大到数据读取。

## 练习五：检测闭环

为靶场增加：

- 请求关联 ID。
- 查询模板 ID。
- 数据库错误分类。
- 修复前后的日志对照。
