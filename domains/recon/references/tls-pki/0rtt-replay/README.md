# TLS 1.3 0-RTT 重放风险

本专题用于学习 TLS 1.3 Early Data 的信任边界、重放条件、最低影响验证、修复与复测。

固定闭环：

`范围 → 基线 → 攻击面 → 假设 → 最低影响检查 → 证据 → 停止 → 修复 → 复测`

- [公开来源索引](./公开来源索引.jsonl)

# 核心内容

- 0-RTT 启用状态、方向和实现默认值。
- 路由副作用与 Safe/Idempotent 判断。
- ticket、ClientHello、external PSK 与反重放状态作用域。
- 多节点、重启、故障切换和 replay store 失败。
- `Early-Data` 风险传播与 425 重试。
- QUIC/HTTP3 恢复参数和 DTLS 双重放平面。
- 最低影响验证、证据等级、停止条件、修复和复测。

# 安全边界

- 仅限自有、明确授权、实验室或虚构目标。
- 主动检查只允许 loopback、容器、自签名证书、合成标签和一次性计数器。
- 不接触真实 ticket、PSK、Cookie、私钥、key log、用户流量或生产服务。
- 不执行公网重放、并发重放、压测、DoS、持久化或真实副作用。
- 记录观察、假设、证据、停止点和复测结果。
