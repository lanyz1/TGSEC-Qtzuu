# GitHub Dorks
A collection of GitHub search techniques, reconnaissance notes, and research resources for authorized security testing and open-source intelligence.

---

# Overview
GitHub is a public code hosting platform where developers store:
- Source code
- Documentation
- Configuration files
- Project history
- Development resources
- Public research material

During security research, GitHub reconnaissance can help identify publicly available information related to an organization's assets.

---

# Purpose
This section focuses on:
- Repository discovery
- Code intelligence
- Technology identification
- Public resource mapping
- Security research preparation

Always verify ownership, scope, and authorization before using discovered information.

# Security Research Notes
Public code does not automatically represent a vulnerability.

Consider:
- Is the repository authorized for review?
- Is the information public intentionally?
- Does the information create security impact?
- Is the affected asset within scope?

---

# Responsible Research
Follow these principles:
- Respect ownership
- Avoid accessing unauthorized systems
- Do not misuse discovered information
- Protect sensitive data
- Follow disclosure policies

# Important Notes
GitHub reconnaissance is an information-gathering activity.
The goal is to understand publicly available resources and improve security awareness through responsible research.

Always follow:
- Authorization requirements
- Bug bounty rules
- Responsible disclosure practices
- Legal boundaries
