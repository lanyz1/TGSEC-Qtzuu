# Lab 11 — HTML Comment Context XSS

## 🎯 Objective
Learn how Cross-Site Scripting (XSS) can occur when user-controlled input is placed inside an **HTML Comment Context**.
This lab focuses on understanding HTML parsing and how an attacker may attempt to escape the context where their input is placed.

---

## 🧩 Scenario
The application allows a user to submit a comment.
The submitted value is processed by the Flask application and inserted into the HTML page.
However, the input is not displayed as normal page content.
Instead, it is placed inside an HTML comment.
Your job is to investigate how the browser interprets this input and determine whether the comment context can be broken.

---

## 🎯 Mission
Your mission is to:
1. Identify where your input is inserted.
2. Determine the HTML context containing your input.
3. Inspect the generated HTML.
4. Understand how HTML comments are parsed by the browser.
5. Determine whether you can escape the current context.
6. Prove whether JavaScript execution is possible.

---

## 💡 Hints
### Hint 1
Don't only look at what appears visually on the page.
Inspect the generated HTML.

### Hint 2
Find the exact location where your input is inserted.
Ask yourself:
    Is my input inside HTML text?
    An attribute?
    JavaScript?
    CSS?
    A comment?

### Hint 3
HTML comments have specific opening and closing syntax.
Think about what happens if user-controlled data contains characters that affect the comment structure.

### Hint 4
Look closely at how the template handles the user input.

---

## 🔎 Investigation
Start by tracing the input from the URL to the server.
Look for:
    request.args.get()

Then determine where the value is passed inside the template.
Finally, inspect the HTML source generated by the application.

The goal is to understand the complete data flow:
    User Input
        ↓
    Flask
        ↓
    Jinja Template
        ↓
    HTML Document
        ↓
    Browser Parser

---

## 🏁 Goal
Successfully demonstrate that the user-controlled input can escape its original HTML Comment Context and cause JavaScript execution.
Use only a harmless proof of concept in this local educational lab.

---

## ▶️ Running the Lab
Install the required dependency:
    pip install -r requirements.txt

Run the application:
    python app.py

Then open:
    http://127.0.0.1:5000

## 🧠 What You Should Learn
By completing this lab, you should understand:
- What an HTML Comment Context is
- How browsers parse HTML comments
- How context breaking works
- Why XSS depends on the location of user-controlled data
- How to inspect generated HTML
- How Jinja handles template output
- Why unsafe template rendering can lead to XSS
- How to identify the difference between HTML content and HTML comments
