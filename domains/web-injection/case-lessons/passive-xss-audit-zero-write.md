# 零写入被动审计方法论 (luankao.top XSS 案)

**原则**: 全程不向目标写任何数据 (不改系统状态), 以"等效路径验证"为核心 — 适用"要正规报告/不能动数据"的交付型审计

## 方法
1. **等效路径验证**: 直接写状态会留痕 → 找"同代码路径但只读"的等价接口, 验证漏洞存在性
2. CSRF 审计: 有/无 token 两请求 A/B 对比
3. 前端点击计数/行为指纹辅助判断可达性
4. 爆破防护审计: 少量探针 + 策略推断 (验证锁定/限速而不实际爆破)

## 教训
- 审计交付物 = 已验证清单 + 已排除清单 (双语对账); 与 fina.icu 非破坏审计同源, 可作模板
