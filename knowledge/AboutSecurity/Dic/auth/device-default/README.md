# 政府/政务设备默认口令（Dic/auth/device-default）

## 说明

本目录收录政府/政务及政企内网常见**安全设备**与**OA 系统**的默认口令（出厂初始口令），
用于授权范围内的资产默认口令核验、等级保护测评与弱口令排查。

## 收录范围

- 安全设备：防火墙、VPN、安全审计、日志审计（天融信、华为、H3C、启明星辰、深信服、安恒、绿盟、网神、联想网御、中新金盾、冠群金辰、黑盾等）
- OA 系统：致远 OA、泛微 OA
- 行格式：`用户名:密码`（与 `Dic/auth/credential-pair.txt` 一致）

## 授权边界与合规声明

- 本字典**仅限**在获得授权的渗透测试、等级保护测评、默认口令自查等场景中使用；
- **禁止**用于未授权系统、生产环境或任何非法用途；
- 本字典**不包含**生产凭据、数据泄露中的真实账号密码、个人信息；
- 部分条目为历史出厂默认口令，厂商可能已强制改密或版本间存在差异，实际以设备型号与固件为准；
- 原文「深信服防火墙 admin/admim」按原文收录（疑为 admin/admin 笔误），`admin:admin` 已同时收录。

## 新增文件注意事项

- 新增字典文件时同步更新 `_meta.yaml` 的 `lines`、`description`、`usage`、`tags`；
- 新条目必须可说明来源与产品范围，不收录来源不明的凭据。
