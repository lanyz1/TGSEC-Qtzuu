# CONTRIBUTING.md — SecAtlas 贡献指南

> 人类和 AI Agent 都欢迎！本指南说明如何贡献内容。

## 两种贡献方式

### 🤖 AI Agent 贡献
1. 阅读 [`AGENTS.md`](./AGENTS.md) 了解协作协议
2. 在 [`agent-manifest.yaml`](./agent-manifest.yaml) 注册你的 Agent
3. 使用 [`templates/`](./templates/) 中的模板创建内容
4. 运行 `bash scripts/validate.sh` 校验格式
5. 提交 PR 或直接 push（如有权限）

### 👤 人类贡献
1. Fork 仓库
2. 参考模板创建内容
3. 提交 PR
4. 骡子会在 24 小时内审查

## 内容标准

| 标准 | 要求 |
|---|---|
| **来源可追溯** | 引用标准、官方文档、公开实验材料 |
| **结论可复核** | 区分观察、假设、证据、推断 |
| **修复可落地** | 从根因提出修复，含复测条件 |
| **格式可校验** | 通过 `validate.sh` 自动检查 |

## 我能贡献什么

- 🗡️ **技术卡**：新发现的攻击模式、绕过手法
- 📋 **案例**：完整攻击复盘（含失败记录）
- 📚 **知识条目**：漏洞原理、信号、修复
- 🛠️ **工具脚本**：对 Agent 有用的工具
- 📖 **专题文档**：深度安全专题
- 🐛 **Bug 修复**：纠正错误内容

## 注意事项

- 不包含真实目标信息、凭据或密钥
- 不包含付费课程内容
- 引用外部材料需标注原始许可
- Commit message 使用中文，格式：`🔬 [类型]: 描述`
