# 许可与第三方材料说明

SecAtlas 是由多种来源和不同类型产物组成的知识仓库，当前**不使用一个根许可证覆盖全部内容**。

## 适用顺序

判断某个文件能否复制、修改或再分发时，请按以下顺序确认：

1. 文件头、同目录的许可说明或来源清单。
2. 原始来源页面、上游仓库及其对应版本的许可证。
3. 如果以上位置均未给出明确授权，则不要推定该内容属于开源或可自由再分发。

文件级或上游许可证始终优先于本说明。仓库中的目录结构、品牌或聚合展示不会改变第三方材料原有的权利状态。

## 内容类型

- **公开标准与官方文档**：版权及使用条件归对应标准组织或发布方所有。
- **案例与实验资料**：以资料自身的作者声明、平台规则和许可为准。
- **仓库原创整理**：在文件没有单独许可证时，默认保留权利，不自动授予再分发许可。

## 引用不是授权

注明来源是研究和学术引用的基本要求，但引用本身不等于获得复制、商用或再分发授权。使用者应独立核验所选材料在其用途和司法辖区下是否合规。

## 权利与撤回请求

如果你是相关材料的权利人，认为归属或许可有误，可以通过 GitHub 联系仓库维护者，并提供文件位置、权利依据和期望处理方式。
