# AI Agent / MCP 安全专题

本专题将 Agent、MCP、RAG、记忆、工具链和执行隔离纳入 SecAtlas 的统一闭环：

`攻击面 → 假设 → 最小影响验证 → 证据判断 → 修复 → 回归复测`

## 内容入口

- [AI Agent 攻击面与控制对](./攻击面与控制对.md)
- [证据、停止点与复测清单](./证据、停止点与复测清单.md)
- [来源与取舍](./来源与取舍.md)

## 范围

- 外部内容注入：网页、RAG、记忆、工具返回、Skill reference
- 工具供应链：Tool/Rug Pull、Shadow Tool、Schema 漂移、跨 Server 冲突
- 身份权限：主体、租户、对象和动作级服务端授权
- 控制流：循环失控、任务自评、Token/费用/外呼上限
- 执行隔离：文件、网络、子进程、代码执行和宿主挂载
- 证据合同：请求/响应、调用序列、控制组、差异、停止原因和副作用

本专题默认使用无害占位符和隔离环境，不复制完整武器化载荷或真实凭据。
