# 云元数据与工作负载身份安全

本专题用于学习自有系统、明确授权项目或隔离靶场中的云元数据、工作负载身份和资源授权边界。

## 测试流程

1. 明确授权目标、身份、允许动作、禁区和停止条件。
2. 枚举输入源、执行主体、元数据/凭据入口、身份交换、云 API 与数据出口。
3. 分开记录已观察事实与待验证假设。
4. 选择不会读取真实凭据、不会产生外部副作用的最低影响检查。
5. 预先定义支持、否定和证据不足三类判定。
6. 达到证据阈值、触及真实秘密或无法保持隔离时立即停止。
7. 修复可达性、身份绑定和资源授权的根因，并用同一场景复测。

## 专题入口

1. [攻击面与测试思路](./攻击面与测试思路.md)：测试流程、攻击面和跨云观察重点。
2. [低影响验证与证据清单](./低影响验证与证据清单.md)：允许动作、证据格式、停止点与复测。
3. [公开资料索引](./公开资料索引.md)：支撑判断的公开一手资料。

## 学习目标

- 从“低信任输入或低权限执行主体”追踪到“云身份和资源动作”的完整路径。
- 判断元数据可达性、身份签发、资源授权分别需要什么证据。
- 识别节点身份泄露、宽泛联邦绑定、共享身份、凭据链覆盖和观测盲区。
- 使用控制面配置、本地 stub、无权限测试身份和负向断言做最小验证。
- 把扫描结果、单一网络事件和日志缺失保留为线索，而不是升级为已验证漏洞。
- 输出根因修复、同场景复测和明确残余风险。

## 使用边界

- 公开资料只能提供知识，不能授予真实目标测试权限。
- 场景固定为 `authorization: lab`，资源、身份、日志和结果均为虚构。
- 不做 DoS、持久化、无界爆破、真实凭据收集、生产写入或范围外探测。
- 一旦需要接触真实秘密、真实资源副作用或未授权资产，必须停止。
